# Recipe Blog Project 🍳

Ένα πλήρως λειτουργικό και δυναμικό Blog συνταγών μαγειρικής, υλοποιημένο με **PHP, MySQL, HTML5, CSS3** και **JavaScript**. Το project διαθέτει ένα πρωτότυπο UI σε μορφή βιβλίου και επιτρέπει την πλήρη αλληλεπίδραση των χρηστών.

## 🚀 Λειτουργίες

- **Σύστημα Χρηστών:** Εγγραφή, Σύνδεση και Προφίλ Χρήστη.
- **Δυναμικές Συνταγές:** Προβολή υλικών και εκτέλεσης με εφέ αλλαγής σελίδων βιβλίου.
- **Διαδραστικότητα:** 
  - Προσθήκη συνταγών στα "Αγαπημένα" (Like system).
  - Σχολιασμός κάτω από κάθε συνταγή.
- **Αναζήτηση:** Δυναμική μπάρα αναζήτησης (Search Bar) για γρήγορη εύρεση συνταγών.
- **Διαχείριση:** Οι χρήστες μπορούν να ανεβάσουν τις δικές τους συνταγές και να διαχειριστούν τις αναρτήσεις τους.

## 🛠️ Τεχνολογίες

- **Backend:** PHP (Σύνδεση με MySQL μέσω PDO/MySQLi).
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla/jQuery).
- **Βάση Δεδομένων:** MySQL (μέσω XAMPP/phpMyAdmin).
- **Assets:** Google Fonts & Font Awesome (μέσω Cloudflare CDN).
