# Recipe Blog Project 🍳

A fully functional and dynamic cooking recipe blog, built with **PHP, MySQL, HTML5, CSS**, and **JavaScript**. The project features a unique book-style UI layout and offers full user interaction.

## 🚀 Features

- **User Authentication System:** Secure User Registration, Login, and personalized User Profiles.
- **Dynamic Recipes:** Modern layout displaying ingredients and cooking steps with elegant book-page turning effects.
- **Interactivity & Engagement:** 
  - "Favorites" system (Like system) to save preferred recipes.
  - Interactive comment section under each recipe post.
- **Search Functionality:** Dynamic Search Bar for quick, real-time filtering and locating of recipes.
- **Content Management:** Registered users can upload their own culinary creations and easily manage their published posts.

## 🛠️ Tech Stack

- **Backend:** PHP (Database communication handled securely via PDO/MySQLi).
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
- **Database:** MySQL (Managed through XAMPP / phpMyAdmin).
- **Assets & Icons:** Google Fonts & Font Awesome (integrated via Cloudflare CDN).
